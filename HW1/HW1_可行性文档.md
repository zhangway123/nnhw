# HW1 语义分割作业 — 可行性分析文档

> 本文档基于 `HW1.docx` 作业要求编写，围绕**端到端弱监督 VQ-U-Net** 方案，分析技术栈、系统架构与实验方法三个层面的可行性。
> 相较此前的「纯 VQ-VAE 重构预训练 + 码本聚类」路线，本文档已按实验证据改为**点弱监督 + 超像素原型 + 图割伪标签 + 在线 VQ 瓶颈**，原无监督聚类相关内容已删除（仅在消融中保留纯 VQ 重构预训练作为反例）。

## 1. 作业概述

### 1.1 任务定义

本作业为**图像语义分割（Semantic Segmentation）**任务：

- 输入：极地环境下的南极动物图像（企鹅、海狮、海豹等多类动物，像素级分割目标）；
- 输出：与输入同尺寸的像素级类别标签图，精确标识不同类别动物所在的像素区域；
- 核心难点：**数据集未经标注**，需自行设计弱监督学习流程构建训练目标。

### 1.3 方案定位

| 环节     | 做法                                                              |
| ------ | --------------------------------------------------------------- |
| 弱标签    | `outputs/label.json`：9 张图、19 个点、4 类动物；每实例 1 个中心点，可加外观点，权重在配置中固定         |
| 初始伪标签  | SLIC 超像素 + 颜色/纹理/LBP/边缘/位置特征 → 点硬约束的类别原型 + 边界超像素背景原型 → 多类图割 |
| 分割模型   | 轻量 U-Net + VQ 瓶颈 + 跳连解码器 + 1×1 分类头，**随机初始化，不做重构预训练**            |
| 训练     | 点窗口 CE + 高置信伪标签 CE/Dice + 增强一致性；码本 EMA 在线更新，不预训练                 |
| 自训练    | 2\~3 轮，EMA 教师重生成伪标签，置信度过滤，点优先                                   |
| 推理     | letterbox 1024 推理，裁 padding 还原原图，CRF/SLIC 投票 + 连通域后处理；仅对 `test_photo` 输出分割图 |

方案的核心特征：**VQ 只承担瓶颈正则与特征离散化，不提供任何类别原型**；初始伪标签完全来自「点 + 超像素 + 图割」，与 VQ 解耦，因此码本不会背上「背景主导」的锅。

## 2. 可行性分析

### 2.1 技术可行性 —— 高

| 技术路线                    | 成熟度 | 说明                                                     |
| ----------------------- | --- | ------------------------------------------------------ |
| 点监督语义分割                 | 高   | 每实例 1 个点即可提供类别监督，配合窗口 CE 是经典做法（Bearman 等，ECCV 2016）    |
| 超像素 + 图割伪标签             | 高   | SLIC 与多类图割（alpha-expansion）均为成熟算法，无需训练，CPU 上每张图秒级        |
| VQ 瓶颈 + U-Net          | 中高  | VQ-VAE 的量化瓶颈已有稳定实现；用于分割任务时仅作正则项，不承担生成目标                 |
| 自训练 / 教师-学生一致性         | 高   | Mean Teacher、FixMatch 等范式可直接迁移，用于把少量伪标签扩散到全量数据         |

四条技术互补：超像素+图割负责**把点传播成像素级伪标签**，VQ-U-Net 负责**学习可泛化的像素分类器**，自训练负责**把监督从 9 张标注图扩散到全量**，后处理负责**修复边界与小连通域**。

### 2.2 数据可行性 —— 中高

有利因素：

- 目标（动物）与背景（冰、雪、海、天空）对比明显，颜色与纹理可分性强；
- 类别集合规模小（背景 + 企鹅 / 海狮 / 海豹 / 其他动物），语义空间简单；
- 点标注成本极低：19 个点即可覆盖 9 张图中的全部实例，标注耗时在分钟级；
- 已提供本地样例（`train_eval_photos/` 约 150 余张，`test_photo/` 6 张）可用于原型验证。

挑战与应对：

| 挑战             | 应对方案                                            |
| -------------- | ----------------------------------------------- |
| 点数量极少（9 张图 / 19 点） | 超像素原型 + 图割先扩成稠密伪标签；再靠自训练扩散到无标签图                 |
| 类别数未知          | 初始设定背景 + 4 类动物，用点所属类别与人工抽检确定，不靠聚类数反推             |
| 原图极大（约 6354×4236） | 伪标签阶段用原图分辨率生成；训练用随机裁剪图块；推理用 letterbox 1024       |
| 目标可能只占少量超像素    | 点硬约束保证种子不被图割改掉；自训练时点监督始终保留                     |
| 雪地高光/低对比       | 特征侧加入 LBP 纹理与边缘强度；后处理加 CRF/SLIC 投票               |

### 2.3 算力可行性 —— 高

本机配备 **NVIDIA GeForce RTX 5060 Ti 16GB**（Blackwell 架构），可独立支撑全部计算：

- 模型为轻量小 U-Net（编码通道 32/64/128/256），512×512 训练下 batch 可取 16 甚至更大，单轮在分钟级；
- 16GB 显存对 640×640 训练与 1024×1024 推理均有余量，无需梯度累积即可完成主线实验；
- 伪标签阶段（SLIC + 图割）为 CPU 离线一次性计算，每张图秒级，不占用显存；
- 自训练 2\~3 轮为纯推理 + 训练循环，时间可控；
- Google Colab / Kaggle 仅作应急备份。

### 2.4 方案演进与决策依据（关键）

早期尝试的「纯 VQ-VAE 重构预训练 + 码本聚类」路线未达到语义分割要求，实验证据如下：

| 证据        | 观测值                              | 含义                                |
| --------- | -------------------------------- | --------------------------------- |
| 码本利用率     | 0.586%（6/1024）                   | 1024 个码只有 6 个在工作，语义容量被锁死在 6 个码     |
| 重建 PSNR   | 11.74 dB                         | 重建收益主要来自背景平坦区域，动物细节几乎未恢复          |
| 训练曲线      | eval loss 自第 2 个 epoch 起上升，11 轮早停 | 训练样本约 134 张，模型在记忆背景而非学习通用结构       |
| 目标尺度      | 6354×4236 → 512 → ×16 → 32×32     | 动物主体仅占 1\~2 个潜变量格，像素级边界无从谈起        |

由此形成三条决策：

1. **取消纯 VQ 重构预训练作为主路线**，仅保留为消融 E2 的反例；
2. **初始伪标签改由「点 + 超像素原型 + 图割」产生**，与 VQ 完全解耦，避免噪声从码本传导到标签；
3. **VQ 降级为瓶颈组件**：随机初始化、EMA 在线更新，只做特征离散化与正则，不提供初始原型。

报告中可直接引用如下表述：

> 纯 VQ-VAE 重构预训练因背景像素主导、小目标令牌不足，初始码本偏背景，故不作为主路线；改为超像素伪标签初始化 + 在线 VQ 瓶颈。

### 2.5 风险分析

| 风险                    | 等级  | 缓解措施                                        |
| --------------------- | --- | ------------------------------------------- |
| 点太少导致过拟合 / 伪标签错误       | 中   | 强数据增强 + 增强一致性损失 + 自训练；并用 E0 普通 U-Net 作为对照基线 |
| 超像素不贴合目标边界            | 中   | 多尺度 SLIC、图割平滑、CRF/SLIC 投票后处理；用 Boundary IoU 量化 |
| 图割多类结果不稳定             | 中   | 限制类别数；类别原型取多个种子的均值；对边界带超像素加背景硬约束            |
| 码本崩溃（dead codes）       | 中   | 小码本（64/128/256）+ 死码重启 + 适度承诺损失；码本不作为标签来源    |
| 自训练确认偏误               | 中   | 点监督始终保留并优先覆盖；置信度阈值 + 每轮抽样人工核验                |
| CRF 依赖安装失败（Windows）    | 低   | 后处理主用 SLIC 投票 + 形态学，CRF 作为可选增强              |
| 训练轮数/时间超限             | 低   | 全流程脚本化，先用 10 张图冒烟测试再全量                      |

**结论：本方案在技术、数据、算力三个维度均可行，主线为「点弱监督 + 超像素图割伪标签 + 在线 VQ 瓶颈 + 自训练」。**

## 5. 实验方法设计

### 5.1 数据与划分

1. **数据盘点**：统计图像数量、分辨率分布、格式（jpg），排查异常文件；
2. **目录固定**：训练集为 `train_eval_photos/`，测试集为 `test_photo/`（6 张）。测试集只做推理并输出分割图，不参与训练与调参；
3. **划分**：
   - 标注集：`outputs/label.json` 中的 **9 张图 / 19 个点**（已完成标注，类别 1\~4 齐全）；
   - 其中留 **1 张**作验证（`5N0A1577_1.jpg`，class 1，1 点，不参与训练），用于早停与超参选择；其余 8 张（18 点）参与训练；
   - `train_eval_photos/` 其余图像（约 150 张）作为**无标签部分**，在自训练阶段参与训练；
4. **评估参考**：在 `train_eval_photos/` 内另标 10\~20 张像素级掩码（**仅用于评估，不参与训练**）；无参考时至少报告点准确率与定性结果；
5. **预处理**：
   - 伪标签阶段：在原图分辨率上做 SLIC 与图割（保留边界细节）；
   - 训练阶段：随机裁剪 512×512（或 640×640），归一化到 `[0,1]` 后减均值除标准差；
   - 推理阶段：letterbox 到 1024（见 5.7）。

### 5.2 阶段 0：点弱标签（已完成）

标注结果见 `outputs/label.json`，字段与统计见 `nonsupervise.md` 第 1 节。

| 项目   | 规则                                                    |
| ---- | ----------------------------------------------------- |
| 标注数量 | 9 张图、19 个点、4 个类别（类别 1：3 图 12 点；类别 2/3/4：各 1\~2 图、1\~3 点） |
| 点位置  | 每实例取 1 个中心点；斑纹明显（如企鹅颈部斑纹）时可加 1\~2 个外观点                  |
| 类别   | 图像级 `label` 字段（字符串 `"1"`\~`"4"`），整张图所有点同属该类；背景不点，由边界超像素生成 |
| 权重   | 文件不含权重，统一在配置中给定：每点 1.0，按图像内点数归一，避免大实例主导                   |
| 产出   | `outputs/label.json`：`[{image name, label, point: [{x, y}]}]` |

坐标是**原图分辨率**，所有几何增强与 letterbox 必须同步变换点坐标；用 `src/weak_labels/validate_labels.py` 校验缺图、越界点与类别缺失。

### 5.3 阶段 1：超像素原型 + 图割 → 初始伪标签

**① SLIC 超像素**

- `n_segments` 按图像面积自适应（如 `面积/1200`，约 2000\~4000 个超像素），`compactness` 10\~20；
- 在 Lab 空间上做 SLIC，保留原图分辨率。

**② 超像素特征**

| 特征块 | 内容                                            | 权重（归一化后） |
| --- | --------------------------------------------- | -------- |
| 颜色  | Lab 均值与标准差                                    | 1.0      |
| 纹理  | 灰度 LBP 直方图（uniform，P=8，R=1）                    | 0.5      |
| 边缘  | Sobel 梯度幅值均值 + 超像素外边界平均梯度                     | 0.5      |
| 位置  | 归一化质心 `(x/W, y/H)`                            | 0.1      |

各特征块分别做 z-score，再按上表加权拼接，避免某一维度量纲主导。

**③ 类别原型（点硬约束）**

- 对每个类别 $c$，取其所有点所在超像素的特征均值作为原型 $p_c$；
- 点所在超像素在能量项中被**硬约束**为该类（不可被图割改动）——这是全流程唯一的人工真值，必须锁死。

**④ 背景原型（边界超像素）**

- 取图像四周边界带（如外侧 3% 宽度）内、**不含任何点**的超像素，其特征均值作为背景原型 $p_{bg}$；
- 对不含点的边界带超像素额外加背景硬约束，抑制图割把背景翻成动物。

**⑤ 多类图割**

在超像素邻接图上最小化：

$$
E(x)=\sum_i D_i(x_i)+\lambda\sum_{i\sim j} w_{ij}\,\mathbb{1}[x_i\neq x_j]
$$

- 数据项 $D_i(c)=\lVert f_i-p_c\rVert^2/2\sigma^2$，硬约束节点置为 $0/+\infty$；
- 平滑项 $w_{ij}=\exp\big(-\lVert \bar c_i-\bar c_j\rVert^2/2\sigma_c^2\big)\cdot(1+e_{ij})$，$\bar c$ 为超像素平均 Lab 颜色，$e_{ij}$ 为共享边界平均梯度；
- 用 `PyMaxflow` 的 alpha-expansion 求多标签近似最优解；
- 输出：超像素标签回填到像素 → 初始伪标签。

**⑥ 置信度**

- 每像素置信度取该点在图割标签上的 softmax 概率 $\max_c \mathrm{softmax}(-D_i)(c)$；
- 硬约束超像素置信度恒为 1，其余按原型距离决定，供阶段 3 的阈值过滤使用。

### 5.4 阶段 2：VQ-U-Net 结构

```
x [B,3,H,W]
 → Encoder：4 个 stage，通道 32/64/128/256，每 stage 2×[Conv3×3 + GroupNorm + SiLU]，stage 间 stride 2
 → Conv1×1 降到 D 维（32 或 64）
 → VQ 瓶颈：最近邻查表（K 个码），直通估计，EMA 更新
 → Decoder：4 个 stage，上采样 + 与 encoder 跳连 concat + Conv3×3 + GroupNorm + SiLU
 → Conv1×1 分类头 → C 类 logits（×8 或 ×16 上采样到输入尺寸）
 → 可选重构分支：解码器末级特征 → Conv1×1 → 3 通道 → Sigmoid（仅正则）
```

| 组件    | 设置                                                     |
| ----- | ------------------------------------------------------ |
| 归一化   | GroupNorm（batch 小，BN 不稳定）                              |
| 激活    | SiLU                                                   |
| VQ 下采样 | ×8 或 ×16（消融 E5）                                        |
| 码本    | K = 64 / 128 / 256，维度 D = 32 / 64（消融 E5）                |
| 码本更新  | EMA（decay 0.99）+ 死码重启（每 100 step 用当前 batch 的 $z_e$ 重置未用码） |
| 承诺损失  | $\beta=0.25$，作用在编码器一侧                                 |
| 初始化   | **完全随机**，不加载任何预训练权重                                    |
| 输入尺寸  | 训练 512 / 640，推理 letterbox 1024                          |

VQ 在本方案中的角色被严格限定：**特征离散化 + 瓶颈正则**。它不参与伪标签生成，也不作为类别原型来源。

### 5.5 阶段 3：弱监督训练

总损失：

$$
\mathcal{L}=\lambda_p\mathcal{L}_{point}+\lambda_s\mathcal{L}_{pseudo}+\lambda_c\mathcal{L}_{consist}+\lambda_r\mathcal{L}_{recon}
$$

| 损失项        | 定义                                                                                    | 默认权重   |
| ---------- | ------------------------------------------------------------------------------------- | ------ |
| $\mathcal{L}_{point}$  | 以每个点为中心的 $r\times r$ 窗口（$r=2\sim5$）内做 CE，类别为该点类别，按实例等权                                | 1.0    |
| $\mathcal{L}_{pseudo}$ | 仅在置信度 $\ge\tau$ 的像素上做 CE（低置信设 `ignore_index`）+ 逐类 Dice 平均                              | 1.0    |
| $\mathcal{L}_{consist}$ | 弱增强与强增强两路预测的一致性（KL 或 MSE），目标侧 stop-grad；可用 EMA 教师的弱预测                                    | 0.1\~0.3 |
| $\mathcal{L}_{recon}$  | 解码器末级特征重建输入（MSE），**仅作正则，不主导训练**                                                        | 0.02\~0.05 |

要点：

- **点窗口要小**。窗口过大等于把点当区块真值，会污染邻近背景；实际以 5×5\~11×11 为主，可作超参；
- **伪标签 CE 必须按类别频率反比加权**，否则背景像素仍会主导梯度（这正是旧路线失败的原因）；
- **Dice 按类平均**，进一步缓解极端类别不平衡；
- 重构项权重必须低，任何"重建指标变好但分割变差"的现象都说明该项过强。

| 超参数    | 取值                                        |
| ------ | ----------------------------------------- |
| 优化器    | AdamW，lr = 1e-3（随机初始化，可略高于微调）              |
| 权重衰减   | 1e-4                                      |
| 调度器    | Cosine Annealing + 前 5% warmup             |
| Batch  | 8\~16（512 训练）                              |
| Epochs | 60\~100，早停（验证图的点准确率 + 伪标签 IoU 连续 5 轮不升）    |
| 混合精度   | AMP（fp16）                                 |
| 早停依据   | 留出的 1 张点标注图（不参与训练）                        |

### 5.6 阶段 4：自训练

| 项目    | 做法                                                                 |
| ----- | ------------------------------------------------------------------ |
| 轮次    | 2\~3 轮                                                             |
| 教师    | 当前模型的 EMA 副本（decay 0.99）                                          |
| 数据    | 全部训练图（含原先无标签池）+ 点标注图                                             |
| 伪标签   | 教师预测 → argmax；保留置信度 $\ge\tau$（如 0.9）的像素，或用逐类分位数阈值                   |
| 点优先   | **点所在窗口强制覆盖为点的类别**，不参与置信度过滤，作为每轮的锚点                               |
| 训练方式  | 以上一轮权重初始化，继续用 5.5 的损失训练；点监督项全程保留                                  |
| 防漂移   | 每轮抽 3\~5 张预测图人工核验；若某类 IoU 连续下降则回退上一轮权重                             |

### 5.7 阶段 5：后处理与推理

**后处理（训练后、每轮自训练后各执行一次）**

1. **CRF / SLIC 投票**：优先 `pydensecrf`（5 次迭代，颜色 + 位置高斯核）；安装失败时退化为「每超像素取平均概率的 argmax」；
2. **去小连通域**：删除面积小于图像 0.5% 的孤立连通域；
3. **保留点所在连通域**：对每个点，在同类掩码中定位包含该点的连通域并保留；只删除「未被任何点覆盖且面积小于阈值」的同类孤立块，面积较大的同类区域不删，避免漏掉图中的第二个动物；
4. **点一致性检查**：若最终掩码在点处与点的类别不符，强制回填点的类别，保证监督锚点不被后处理抹掉。

**推理（仅 test_photo）**

1. **letterbox 1024**：`scale = 1024 / max(H, W)`，长边缩放到 1024，短边居中 padding 到 1024×1024，记录 `scale` 与 `pad`；
2. 前向得 `[1, C, 1024, 1024]` logits，argmax 得掩码；
3. **裁 padding**：按记录的 `pad` 裁回 `round(W·scale) × round(H·scale)`；
4. **还原原图**：最近邻上采样到 `(H, W)`（或直接按原图尺寸做一次 resize）；
5. 执行 5.7 后处理；
6. **输出分割图**到 `outputs/pred/test_photo/`：`{stem}_mask.png`（uint8 类别 ID）、`{stem}_color.png`、`{stem}_overlay.png`、`{stem}.json`（尺寸 / scale / pad / 各类占比）；
7. 指标不在测试集上计算，统一在评估子集上按 5.8 汇总。

### 5.8 评价指标（≥5 个）

| 指标                             | 公式（简述）                              | 作用              |
| ------------------------------ | ----------------------------------- | --------------- |
| **mIoU**                       | 每类 IoU 的均值，IoU = TP/(TP+FP+FN)       | 核心指标，评价像素级分割精度  |
| **mAcc**（类别平均准确率，即 mPA）         | 各类 PA 的均值                           | 关注少数类表现         |
| **Pixel Accuracy (PA)**        | 正确像素数 / 总像素数                        | 全局精度            |
| **Dice / F1**                  | 2·TP/(2·TP+FP+FN)，逐类计算后取均值           | 类别不平衡下的稳健指标     |
| **Boundary IoU**               | 在边界带内计算 IoU                         | 边界质量（本方案重点）     |
| **每类 IoU**                     | 逐类列出                                | 定位哪一类被吞并 / 混淆   |
| **点准确率**                       | 点在预测掩码处的类别与标注一致的比例                  | 弱监督专属的锚点校验指标    |

说明：训练为弱监督，指标需在评估参考（5.1 第 4 条）上计算；测试集 `test_photo` 无真值，只输出分割图、不报指标。同时报告伪标签质量（初始伪标签与人工小评估集的 IoU），用于区分「伪标签错误」与「模型欠拟合」。

### 5.9 消融与实验安排

| 实验编号 | 变量                                              | 目的                     |
| ---- | ----------------------------------------------- | ---------------------- |
| E0   | 普通小 U-Net + 超像素伪标签自训练（无 VQ）                      | 强 baseline，验证 VQ 瓶颈是否真的有用 |
| E1   | VQ-U-Net，无 VQ 预训练，码本在线 EMA（**推荐主线**）              | 主结果                    |
| E2   | VQ-U-Net + 纯 VQ 重构预训练                           | 反例消融，复现「背景主导、码本偏背景」    |
| E3   | E1 + 自训练 1 / 2 / 3 轮                            | 自训练收益曲线                |
| E4   | 每实例 1 点 vs 2\~3 点                               | 点数量与质量的性价比             |
| E5   | VQ 下采样 ×8 vs ×16；码本 64 / 128 / 256；有无 CRF       | 结构超参与后处理消融             |

每项实验统一记录：训练曲线（各项损失、点准确率）、评估指标（mIoU / mAcc / PA / Dice / Boundary IoU 及每类 IoU）、伪标签质量、代表性可视化（原图 / 初始伪标签 / 预测 / 差异图）。
